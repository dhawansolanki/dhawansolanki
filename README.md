### 🌐 System Architecture & Technical Profile

My work centers on turning cutting-edge AI breakthroughs into seamless, low-latency consumer and enterprise applications.

### 🛠️ Interactive Tech Stack Breakdown

<details open>
<summary><b>🧠 Generative AI, Video Pipelines & Media Processing</b></summary>
<br/>

- **Video Synthesis & Diffusion**: Hands-on inference pipelines for generative video (Wan, Hunyuan Video, CogVideoX, Veo), custom LoRA adapters, ComfyUI workflows, and automated scene generation.

- **Audio & Media Engineering**: FFmpeg hardware acceleration, Whisper speech-to-text alignment, ElevenLabs text-to-speech voice cloning, and subtitle synchronizers.
- **Vector Search & Embeddings**: Semantic retrieval with pgvector, Chroma, and hybrid search ranking.

</details>

<details open>
<summary><b>⚡ Distributed Systems, Backends & Microservices</b></summary>
<br/>

<p align="left">
  <a href="https://skillicons.dev">

</p>

- **Asynchronous Workloads**: Architected resilient job queues using Celery, BullMQ, and Redis for long-running video rendering and AI inference.
- **Real-Time Communication**: Bi-directional WebSockets and Server-Sent Events (SSE) for interactive AI streaming and live worker progress.
- **API Architecture**: High-speed RESTful and GraphQL APIs, JWT/OAuth2 authentication, RBAC, and rate limiting.
- **Concurrency & Reliability**: Distributed locks (Redlock), idempotent transaction handling, and graceful worker shutdown mechanisms.

</details>

<details open>
<summary><b>☁️ Cloud Infrastructure, Kubernetes & Production DevOps</b></summary>

- **Cluster Orchestration**: Production multi-node **Kubernetes** management on Google Kubernetes Engine (GKE) and AWS EKS with GPU autoscaling node pools.
- **Infrastructure as Code (IaC)**: Automated cluster provisioning, VPC peering, and IAM policies via **Terraform**.
- **Reverse Proxies & Networking**: Caddy (automatic TLS), Nginx ingress controllers, Cloudflare CDN caching, and DDoS shielding.
- **CI/CD Pipelines**: Automated multi-stage Docker image builds, vulnerability scanning, and rolling releases via GitHub Actions.

</details>
